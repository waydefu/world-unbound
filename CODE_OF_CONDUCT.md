# Code of Conduct

This project adopts the core principles of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/): a welcoming, respectful environment with zero tolerance for harassment, discrimination, threats, doxxing, or sustained disruptive conduct.

## Expected behavior

- Treat contributors fairly and professionally.
- Debate technical proposals on evidence and merit, not personal identity.
- Respect privacy, ownership, licensing, and security boundaries.
- Accept constructive feedback and explain decisions transparently.

## Unacceptable behavior

- Harassment, intimidation, sexualized attention, or hate speech.
- Publishing another person's personal information without consent.
- Deliberate abuse of issue trackers, pull requests, or CI resources.
- Retaliation against a good-faith reporter.

## Enforcement

The repository maintainer may warn, hide content, restrict participation, or block an abusive account, taking context and severity into account.

For a sensitive report, avoid posting identifying details in a public Issue. Use a private contact method listed on [the maintainer profile](https://github.com/waydefu), if available, or [GitHub's report-content process](https://github.com/contact/report-content). Do not use the vulnerability-reporting route for ordinary interpersonal disputes unless a genuine security threat is involved.

This is the repository's own concise policy, informed by the Contributor Covenant; it is not a verbatim reproduction.
